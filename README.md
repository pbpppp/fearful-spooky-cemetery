# Лабораторная работа №1

Загрузчик ОС: ФИО и группа по центру экрана, овал внизу, всё рисуется попиксельно.

Что где лежит:

- `src/boot.asm` — сам загрузчик (первый сектор)
- `src/font16.asm` — шрифт 8x16, отдельным сектором
- `src/mbr.asm` — загрузочная запись MBR
- `tools/mkimage.py` — сборка образа винчестера с таблицей разделов
- `tools/screenshot.sh` — скриншот экрана из QEMU
- `build/boot.img` — образ дискеты
- `build/disk.img` — образ винчестера
- `screenshots/` — скриншоты для отчёта

Сборка: `make` (нужен fasm, он есть в `shell.nix`).
Запуск: `make run` — с дискеты, `make run-hd` — с винчестера.
